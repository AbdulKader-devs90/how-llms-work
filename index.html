How LLMs work, and MCP

An LLM does not read words. It reads numbers and predicts the next piece of text. MCP lets it use your tools and data. This page shows both.

The main idea

A large language model (LLM) does one task. It predicts the next token.

It adds that token to the text. Then it predicts the next token again. A full answer is this loop, repeated many times.

To make a good prediction, the model uses three tools: tokens, embeddings and attention.

NOTE

The model learned its patterns during training, from a very large set of text. At the time of your question, it does not search the internet. It only uses its learned patterns and the text in its context window.

2

Tokens

A token is a small piece of text. It can be a full word, a part of a word, or a punctuation mark.

The tokenizer changes each token into a number (the token ID). The model works only with these numbers.

In English, one token is approximately four characters. Thus, 100 words are approximately 130 tokens.

This is a simplified tokenizer. Real tokenizers (for example, BPE) learn their pieces from data.

3

Embeddings

A token ID is only a label. It does not show meaning. Thus, the model changes each token ID into a vector (a list of numbers). This vector is the embedding.

Tokens with almost the same meaning get vectors that are near each other.

" pilot" (ID 18213) → [0.41, -0.22, 0.87, 0.05, … 4,096 numbers]
" captain" (ID 28627) → [0.39, -0.19, 0.82, 0.11, … near " pilot"]
" coffee" (ID 18837) → [-0.63, 0.54, -0.12, 0.70, … far from " pilot"]

The model also adds position data to each vector. Thus, it knows the word order. “Pilot checks engine” and “engine checks pilot” have the same tokens, but a different meaning.

NOTE

These are the same kind of vectors that a vector database stores for RAG. See Task 01 for a similarity search demo.

4

Attention

One word can have different meanings in different sentences. Attention lets each token get information from the other tokens in the text.

For each token, the model calculates a weight for each earlier token. A high weight means “this token is important for me”. The model then mixes the vectors with these weights.

The model does this in many layers, and with many attention “heads” in each layer. Each head can find a different type of relation.

Try attention

Click a token. The yellow color shows how much attention it gives to each earlier token. Try “it”.

    The weights on this page are examples. A real model has many heads with different weights.

    5

    Prediction and temperature

    After the last layer, the model gives a probability to each token in its vocabulary. Then it selects one token.

    Temperature controls this selection. A low temperature almost always selects the most probable token. A high temperature gives less probable tokens more chance.

      MCP: connect the model to tools

      An LLM only makes text. It cannot read your live data or do actions in your systems.

      Before MCP, each AI app needed a special connector for each system. Ten apps and ten systems needed up to one hundred connectors.

      MCP (Model Context Protocol) is an open standard for this connection. Anthropic introduced it in 2024. You build one MCP server for a system. Then each MCP-compatible app can use it, like one USB-C plug for many devices.

      Host
      The AI app that the user talks to (for example, Claude Desktop or an IDE).
      MCP client
      The part of the host that connects to one MCP server.
      MCP server
      A small program that gives access to one system, for example a database, a file store or an API.
      Tools
      Actions that the server makes available, for example get_work_order.
      Resources
      Data that the server makes available to read, for example files or records.
      Prompts
      Prepared prompt templates that the server makes available.

      8

      Warnings and cautions

      WARNING

      An LLM predicts probable text. It does not check facts. An answer can sound correct and be wrong. Examine important answers.

      WARNING

      An MCP server can read your data and do actions. Install MCP servers only from sources that you trust. Approve each tool call that changes or sends data.

      CAUTION

      Tool results can contain hidden instructions (prompt injection). Do not let the model obey text that comes from a tool. Treat it as data.

      CAUTION

      Tokens fill the context window and cost money. Many languages, code and numbers use more tokens than plain English.

      NOTE

      The model does not run the tool. The model only asks for the tool call. The host runs it through the MCP client and server.
